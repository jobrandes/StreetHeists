## Flow (only two rooms)

Case Board → Briefing → **Gather** → **Decide** → Verdict.

- **Gather** — Clues we give you (photos, docs, notes). Tap to inspect; takeaways auto-file in Case file.
- **Decide** — Fill Who / How / Where, attach proof from filed clues, Accuse.
- **Case file** — Persistent notebook so you don’t memorize. Open anytime from chrome.

Legacy Confront / Scene URLs redirect into Gather / Decide. Do not rebuild the old 4-tab or 7-room layout.

2. Read docs and notes for clocks, lists, and tells.
3. Optional lab sample pick on some clues.
4. Use Case file as memory.
5. Accuse with evidence-backed Who / How / Where (right person + wrong proof still fails).
